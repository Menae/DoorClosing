Homecoming / Mac試遊版（全4夜）

macOS 12以降、Metal対応のMac向け。Apple Silicon・Intel両対応。
キーボードとマウスを使用します。Unityのインストールは不要です。
Mac実機の動作・性能確認はこれからです。まず作者のMacで確認してください。

起動
1. ZIPをMacへ転送し、Finderで展開します。
2. Homecoming-Macフォルダ内のHomecoming.appを起動します。
3. 「はじめから」で開始します。設定から音量・感度・表示サイズを調整できます。

この試遊版はAppleのDeveloper ID署名・公証を行っていません。
未確認の開発元として止められた場合は、作者から受け取った本ファイルであることを確かめ、
Appleの手順に従い「システム設定 → プライバシーとセキュリティ → このまま開く」を使用します。
Mac全体のGatekeeperを無効にする必要はありません。
「壊れている」「開けない」等、異なる警告が出る場合は文面を作者へ伝えてください。
Appleの案内: https://support.apple.com/ja-jp/102445

操作
WASD：移動　Shift：走る　マウス：視点　左クリック：調べる／操作
Esc：ポーズ／設定／タイトルへ戻る
入力が反応しない場合はゲーム画面をクリックし、キーボードを英数入力にします。

内容
マンションから自宅へ帰る一人称ホラーです。
最初の夜に通常の帰宅を経験し、その後の3夜で怪異に対処します。
ゲーム内の掲示と周囲の変化を手がかりに進めてください。
死亡すると現在の夜から再挑戦できます。
「続きから」は現在夜の入口から再開します。夜の途中の位置そのものは保存しません。
全4夜の帰宅後に結果とスタッフロールへ進みます。

作者のMacで先に確認する項目
□ タイトルが表示され、日本語が読める。ピンク表示や真っ黒な画面がない。
□ 移動・視点・クリック・Escが反応し、足音や設備音が聞こえる。
□ 導入から全4夜を通し、結果とスタッフロールからタイトルへ戻れる。
□ 途中で終了して再起動し、「続きから」で現在夜へ戻れる。
□ 設定した音量等が再起動後も保持される。
□ 遊んだMacの機種・チップ・macOS・表示サイズと、重い場面を記録する。

問題時のログ
Finderの「移動 → フォルダへ移動」で次を開きます。
~/Library/Logs/DefaultCompany/GraduationProject/Player.log
ゲームの保存データは通常次のフォルダに作成されます。
~/Library/Application Support/DefaultCompany/GraduationProject/Homecoming/
ログを渡す前に、ユーザー名など共有したくない情報がないか確認してください。

素材の利用条件・クレジットは同梱licensesフォルダを参照。
