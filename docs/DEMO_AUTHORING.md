# デモの起動と掲示の文章編集

## 起動

`Assets/Scenes/PlayableDemo.unity` を開いてPlay。タイトル→通常帰宅→翌夜の基本3怪異→帰宅→再プレイ／終了がデモの経路。M1NormalRoute／M2VerticalSliceは個別確認用として残す。

## 掲示の編集

Playを止め、Hierarchyの検索欄へ `文章編集` と入力する。

`EntranceHall > 掲示物_文章編集はこちら` の下にある以下のGameObjectを選ぶ。

| Hierarchy名 | 場所・役割 |
|---|---|
| 01_帰宅の手順_文章編集 | 左の掲示板。乗車・８階・自宅と、普段の廊下の確認 |
| 02_困ったときの対処_文章編集 | 左の掲示板。誤操作後の戻り方・待ち方 |
| 03_乗車前の三原則_文章編集 | エレベーター右の壁。怪異を見分ける基本原則 |

Inspectorの **掲示の文章編集 / Editable Notice** にある **見出し・本文** を編集し、Sceneを保存する。子オブジェクトのHeading／BodyのTMPを直接変更しない。専用コンポーネントが表示元なので直接のTMP変更は戻る。文字サイズも同じInspectorで調整できる。長すぎる文章は紙面超過の警告を確認し、実際のGame Viewでも読む。

文章は各Sceneに保存する。PlayableDemoの文章編集は個別確認用M1/M2には自動同期しない。デモ調整はPlayableDemoを編集する。内装のApplyは既存の文章を保持するが、Sceneを元から作り直す操作は文章の保持対象ではない。Create Playable Demoは既存デモを上書きしない。

## 文章調整の基準

- 普段の廊下を導入で覚え、８表示だけで降りない。違う廊下なら車内で「閉」。
- 放送・呼び声だけを根拠に非常停止しない。挑発では入力しない。
- ８を越える階数表示と、速く高くなる走行音の両方があれば非常停止。
- 「異常なら常に非常停止」と書くと誘引・挑発の正解と矛盾する。
- 救済説明はGAME_SPECの条件を守る。誘引は全身を車内へ戻して閉じ切る必要があり、外から閉めても正解にならない。

開始画面は掲示を読む場所と通常帰宅の目的を案内する。読了チェックや閲覧強制は設けていない。初見の人が気づき、理解して使えるかはプレイテストで確認する。

## メニューとビルド

Escで時間・操作・音を一時停止。フォーカスを失った場合もポーズへ。設定は感度／上下反転／視野角／明るさ／音量／表示サイズ・画面切替。設定・進行の永続保存はこのデモの対象外。

`Tools > Unity Agent > Build Playable Demo Windows` はデモSceneを指定した通常Windows buildを作る。出力先と結果はartifactsのbuild記録で確認する。配布にはexeだけでなく同じ出力フォルダーのData等も必要。外部公開は今回の委任に含まない。
