Homecoming / 本編開発用ビルド
GraduationProject.exeを起動。WASD移動、Shift走る、マウス視点、左クリック操作、Escポーズ。
805の郵便受けを調べ、小型操作盤へ805を入力してホールへ進みます。
通常帰宅後は翌夜へ。怪異の組み合わせはビルド時のHomecomingの設定に従います。
全4夜モードでは導入後に怪異3夜、比較モードでは指定した遭遇だけを遊びます。
死亡は現在夜から再開。全4夜モードは進行と設定をPC内に保存します。
Esc→タイトルへ→確認の後、または終了・再起動後に「続きから」を選ぶと現在夜のホールから再開します（導入は入口から）。
時間と死亡数は引き継ぎます。全夜終了時に結果、独立した最短時間・最少死亡数を表示し、次回は導入省略も選べます。
保存先：%USERPROFILE%/AppData/LocalLow/DefaultCompany/GraduationProject/Homecoming
読めないセーブは上書きせず通知します。複数起動を終了し、空き容量とアクセス権を確認してください。
比較モードは保存しません。公開・完成版ではありません。
Data、MonoBleedingEdge、DLLなどを同じフォルダーに保持してください。
