帰宅 / プレイアブルデモ

起動: GraduationProject.exe を実行してください。
exeとGraduationProject_Data、UnityPlayer.dllなどは同じフォルダーのまま保持してください。

自宅は８階です。まず通常の帰宅で廊下を覚え、翌夜の帰宅へ進みます。
乗る前に、エレベーター横と左の掲示板の注意書きを読んでください。

WASD: 移動 / Shift: 走る / マウス: 視点 / 左クリック: 操作
Esc: 一時停止、設定、やり直し、終了
設定: 視点感度・上下反転・視野角・明るさ・音量・画面表示
設定と進行は保存されません。最初から遊ぶと通常帰宅へ戻ります。

デモ内容: 通常帰宅＋基本３系統の怪異を含む１夜。
本編の全４夜、追加演出、進行保存は含みません。
死亡後は怪異夜の入口から再挑戦します。

Windows用。現段階は評価用デモです。
初見で掲示の場所・意味に気づけるか、異常と普通の廊下を比較できるかを評価してください。
音色・怖さの受入、最低動作環境、長時間安定性の認定は未完了です。

素材: 既存Noto Sans JP / TMP。フォントの著作権・ライセンスは同梱licenses参照。
内装テクスチャはプロジェクトで生成した素材。足音・換気・エレベーター音は独自の合成音。
参考写真や「８番出口」の画像そのものをゲーム画面へ貼り付けていません。
